# 0020 稳定的会话写入凭证恢复

状态：accepted；日期：2026-10-22；关联 Issue：#47。补充 ADR 0008、0015。

新标签页拥有 HttpOnly Cookie 却没有 sessionStorage nonce，不应要求重新登录。
同源且严格校验 Origin 的 Cookie 专用 POST /auth/session 返回当前账户和稳定 CSRF。
CSRF 为 HMAC-SHA256(key=原始高熵会话秘密, message="wikit/session-csrf/v1") 的十六进制值，
域隔离且不包含会话秘密；普通写入使用常数时间摘要比较。新登录保存派生凭证摘要，
旧会话同时接受已保存摘要对应的随机凭证，避免升级或另一标签页恢复破坏现有写入。
恢复不旋转凭证、不延长会话、不修改数据库，优先保留现有会话和数据；无需持久化明文
或引入新服务器密钥。此设计取舍是每个会话稳定的写入凭证，而不是每次恢复轮换。

前端启动及缺失凭证时恢复，并合并并发请求；401 需复核会话，避免错误密码导致退出。
恢复网络失败保留草稿，真正失效才要求登录；账户变化卸载草稿，取消或晚到请求不能
复活退出后的身份。失败业务写入交由用户重试，避免重复副作用。
