# 0019 精简 Wiki 导航

状态：accepted；日期：2026-10-22；关联 Issue：#39。用户直接要求本次导航调整。

本决策替代 ADR 0018 中的左侧站点导航、独立目录及辅助全站提案页面安排。
参考 [MediaWiki Vector](https://www.mediawiki.org/wiki/Skin:Vector) 的顶部搜索和页面操作组织方式，
按用户要求移除站点侧边栏，并将阅读、讨论、历史、提案及其他页面工具全部右对齐。

站名链接首页；顶栏保留搜索和账户菜单。
2026-10-22 按用户纠正（Issue #41）：创建入口仅在非空关键词、未附加标签或类型过滤的搜索成功返回零结果时，
向具有 can_create_page 的账户显示，链接将搜索词带入新建表单标题。加载、请求失败、空搜索、有结果或无创建权时不显示。
移除 `/pages` 和 `/proposals` 前台路由，旧地址显示未找到页面；不影响 `/pages/new`、
具体页面阅读、编辑、历史、提案、讨论和权限路由。
2026-10-22 按用户澄清（Issue #43）：Page 之间没有所属或父子层级，首页也不是其他 Page 的父级。
所有页面不使用面包屑；首页通过顶栏站名访问，阅读、编辑、历史、提案、讨论和页面管理通过页面操作进入。
标签跳转 `/search?tag=…`，搜索页统一承载关键词、标签和类型过滤，无关键词时列出匹配页面。
后台账户、用户组、审计与返回站点使用横向导航；保留文章目录及其窄屏 Sheet。

2026-10-22 按用户要求（Issue #45）：页面标题和页面工具共用同一头部，宽度充足时在同一行，标题居左、操作居右。
窄屏及长标题按可用空间换行；保留完整标题和状态徽标，不遮挡操作、不产生页面级横向溢出。
站名、账户、创建、搜索及管理入口保持键盘可达。
保持 Core、REST/MCP、权限与发布规则不变；仅取消前台独立的全站列表页面。
