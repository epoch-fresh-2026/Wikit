# 0021 有界读取与性能测量

状态：accepted；日期：2026-10-22。

保持 ADR 0008 的全局授权锁及业务规则。先测量连接池等待、SQL 次数、锁等待与持有时间，
再减少锁内工作；此阶段不改变锁粒度、worker 或部署拓扑。

搜索在锁外按需取得候选，在授权事务内批量读取当前页面、head 和完整策略。
不足一页才继续请求；跨批次保留的候选在最终返回的事务重新复核当前身份、组、版本和策略。
每请求最多取得 1,000 个候选，结果只从当前数据库快照生成；索引代次变化拒绝旧游标。

页面目录改用数值 Page ID 的 keyset；每批最多 100 个候选，每请求最多扫描 1,000 个。
Core 决定权限，存储仅按发布状态、查询条件、稳定排序和范围读取。完整策略按批读取，
公开页显式授权仍参与 capabilities。过滤后允许空页或短页带游标；客户端按 next_cursor 续取。
游标保存最后实际消费的候选 ID，绑定身份、查询和页大小，10 分钟过期；不是跨请求快照。
翻页之间前方记录隐藏不会造成 offset 位移；新授权且位于锚点之前的页面需从第一页重读。
0009 仅新增可空 bigint 锚点；旧目录 offset 游标返回 invalid_request，其他列表游标保持有效。
REST/MCP 字段结构不变。标签、历史、提案、讨论和管理列表仍保留现有分页，后续另行优化。

测量使用显式附在 context 上的聚合计数，不记录 SQL、参数、查询词、凭证或正文。
基线与优化使用同一工具和隔离服务夹具；延迟数据不构成生产 SLO。权限竞态通过屏障测试。
