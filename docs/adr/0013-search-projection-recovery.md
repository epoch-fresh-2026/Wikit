# 0013 搜索投影与恢复

状态：accepted；日期：2026-10-20；关联 Issue：#8。

Meilisearch 1.55.0 通过 HTTP 小适配器接入，不进入 Core。只有已发布 Page 的当前文本和
授权主体标识进入内部索引；响应正文、标题和标签必须来自数据库当前授权事务。
旧版本候选被跳过并安排修复，不能从搜索服务返回旧摘要、总数或 facet。

worker 使用独立的 PostgreSQL 会话锁串行投递，和重建互斥，不持有业务授权锁等待网络。
outbox 持久化任务 UID，确认异步成功后再完成，失败退避。策略更新以事务触发器追加事件，
避免页面治理、ACL 和内容发布遗漏投影更新；成员变化以当前查询身份过滤。

重建先建立新索引并追赶一个确定水位，再原子切换数据库 active_index 指针。
远端索引准备失败不会切换；切换后未完成事件继续向当前索引投递。此方案免除远端 swap
与本地事务之间的不可原子提交窗口。旧索引保留，旧游标因代次变化失效。
首版不引入并行 worker、语义检索、外部消息队列或未经权限校验的缓存。
