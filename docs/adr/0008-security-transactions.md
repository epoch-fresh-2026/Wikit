# 账户与页面授权事务

状态：accepted；日期：2026-10-20；对应 Issue #3 的已确认范围。

身份模块拥有凭证、账户状态和会话用例；权限模块依赖其公开认证接口并拥有角色矩阵、
组及 ACL 治理。密码/随机源由消费方接口注入，Core 不依赖 Argon2 库、HTTP 或 pgx。
PostgreSQL 适配器通过明确的授权 Unit of Work 同时读取当前身份与策略。

在后续业务事务共享之前，使用固定 transaction advisory lock 串行化安全读写；
迁移仍使用独立锁。后续发布/媒体/讨论用例必须复用此事务边界，不得先鉴权后单独提交。
代价是吞吐受最慢安全事务影响；缩小锁粒度须用确定性竞态测试证明等价后另行推进。
此阶段不实现尚无模型的合并，只测试授权事务边界与撤权提交顺序。

页面 ACL 独立保存于 page_policies，以 Page UUID 关联后续内容模型。页面管理者
不能改变 manage 授权，不能改变自己所在组的授权来扩大自身有效能力；组成员变更
仅管理员可做。受限页面至少保留一个活跃、显式可读的非管理员参与者。
