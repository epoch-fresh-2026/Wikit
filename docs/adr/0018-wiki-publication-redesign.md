# 0018 Wiki 页面、数字 ID 与直接发布

状态：accepted；日期：2026-10-21；关联 Issue：#35。用户已确认完整实施计划。

本决策替代 ADR 0003、0009、0010 中的首次创建提案、UUID Page、审核轮次和批准前置规则；
保留单页面提案、不可变快照、版本条件、原子发布、三方合并、当前 ACL 与媒体安全。

## 发布与权限

Page 使用正 bigint 递增 ID，接口以十进制字符串表达，其他对象保持 UUID。
首页固定为 1，初始化时生成标题“首页”、空正文、空标签的系统首版；不得重复初始化、
删除、隐藏、改为受限或替换。普通账户可提出修改，只有管理员可合并。

管理员向用户或组授予 create_page；新账户默认无创建权，管理员始终有。
创建原子发布首版，返回 page/revision，不创建虚拟提案。作者获得 read/propose/discuss，
不自动获得 merge/manage。发布来源为 bootstrap/create/merge；仅 merge 关联提案，
仅 bootstrap 可没有用户作者。

reviewer 改 moderator（版主），review 能力改 merge。版主可合并普通公开页；受限页
需显式授权。取消审核记录、批准、要求修改、审核轮次和相关 REST/MCP 接口。
合并者直接检查候选差异并合并，可自合并；head 或候选变化必须重新读取，不能强制覆盖。
管理权限不蕴含合并权限，首页例外在 Core 与数据库中保护。

## WebUI

React SPA 使用官方 CLI 安装的 shadcn/ui Radix/new-york/neutral 组件。
前台顶部搜索、左侧导航、中间正文、右侧目录，移动端折叠；移除宣传标题与口号。
根路由读取 Page 1，目录与搜索独立；提案详情和编辑属于具体 Page，辅助全站队列只导航。
后台 accounts/groups/audit 使用独立布局与路由。标签通过 Input/Badge/Button 组合，
回车添加、逐项删除、不分隔字符串；处理中文 IME，提交纳入未确认输入。
草稿仅驻留内存，离开提示；认证切换清理，受限数据不持久化，Core 返回有效操作能力。

## 新部署与验收

本次为新的空库部署基线，不兼容旧 UUID 数据或链接，不自动删除数据。
保留迁移校验以拒绝旧库；回退旧版需要旧镜像与其备份，不能跨 schema 原地降级。
同步所有页面引用、搜索、审计、媒体、OpenAPI/MCP、生成类型、恢复与验收脚本。

验收覆盖初始化幂等、ID 并发、首页保护、个人/组授权与撤销、首版直接发布、
版主合并、冲突与幂等、媒体原子校验、REST/MCP 等价、SPA 深链接、键盘与 IME。
运行全部已启用文档、前端、Go、数据库/搜索、容器恢复及规模检查，不禁用 CI。
