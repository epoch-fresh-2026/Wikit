# 0025 搜索证据与章节定位

状态：accepted；日期：2026-10-24；关联 Issue #61。

页面摘要截取开头不能定位长文中的答案。保留页面级检索及全部词匹配，在 Core 最终权限与当前发布版本复核之后，从数据库快照解析 Markdown 块并选择最多三个相关摘录；索引只提供候选，不提供可信证据正文。
每个摘录包含纯文本、章节路径、章节锚点、源 Markdown 行号、是否截断及固定发布版本引用；片段无独立存储或权限。无正文/章节匹配时返回空片段，不把开头伪称为命中。
关键词在段落和章节路径中按规范化、不区分大小写的子串匹配，每段最多截取 600 字符；不增加向量检索或自然语言查询改写。问题评测分别记录原始问题与提炼关键词的召回和证据定位。
