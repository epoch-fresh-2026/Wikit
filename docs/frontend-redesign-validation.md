# 前端重设计验证

2026-10-23，沿用简洁 Wiki 风格重设计现有前端，不修改 Core、REST/MCP 或权限/发布契约。

## 实现范围

- 统一顶栏、内容宽度、文字层级、留白、列表、表单、标签、加载骨架和空状态；顶栏搜索持续可达。
- 阅读目录呈现标题层级和当前章节，固定顶栏为锚点预留空间；保留移动 Sheet 关闭与焦点恢复行为。
- 搜索筛选与结果分区；讨论状态中文化；历史、提案和管理表单遵循相同的布局节奏。
- 提案 diff 使用增删色与原有 +/- 文本标记，保留原始对比内容和合并条件。
- 编辑正文/预览桌面并排、手机切换，长内容在输入与预览区域内滚动，切换不清空草稿；预览使用 memo/useDeferredValue，提交仍读取即时输入。
- 搜索、编辑、历史与版本组件按路由延迟加载。未添加响应缓存、持久草稿或新的依赖。
- 首页、编辑、管理与固定历史版本显示正确的当前页面工具；路由切换聚焦正文，同页筛选和 Tab 更新不重置滚动。
- 不新增侧边栏、面包屑、全站提案或额外创建入口。保留 v0.1 与 ADR 0019 边界。

- 首页、文档阅读、媒体阅读。

- 发布历史、固定版本。
- 页面提案列表、提案详情、提案编辑。
