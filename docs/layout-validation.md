- Alert 的正文原被自动放进零宽图标列。按官方 Alert / AlertTitle / AlertDescription 结构组合，图标为直接子元素，错误和请求编号可换行。
- 320 CSS 像素视口中，126 个连续拉丁字符标题、63 字符中文标签、64 字符英文标签、64 字符账户显示名使页面宽度达到 2019 像素。修正主内容最小宽度、面包屑、标题、标签、列表和顶栏的换行/收缩后，同一页面 scrollWidth 为 320。
- Badge 业务组合允许标签换行，编辑时删除按钮保留完整点击宽度。未修改官方基础组件源码。
- 窄屏顶栏将搜索独立成行；长账户名截断，完整名称仍保留在按钮可访问名称、title 和账户页面。
- 目录在视口高度内滚动。移动 Sheet 的末项原在可视范围外，且点击章节后默认恢复按钮焦点会把正文拉回原处；现在选择章节会滚动并聚焦标题，Escape 保留返回按钮的行为。
- 审计表格保持局部横向滚动；历史操作栏和分页可以换行；音频宽度受正文约束；Skeleton 改用有效的块级容器。
