# 架构决策

本文按主题维护现行选择、理由和代价。改变重要选择时直接修订对应章节，并同步相关契约；
讨论与批准在开发 Issue 和 PR 中保存，历史方案通过 Git 追溯，不另追加编号、日期或版本补丁。

## 文档职责

需求、业务规则、架构、接口、工程规范及验收分别维护单一职责。业务规则集中维护，
接口引用其语义并定义传输映射；Issue 链接文档章节以说明设计影响和验收范围。
这减少重复规则与修订漂移，代价是跨职责变更必须同时检查所有受影响文档与链接。

## 存储与发布

PostgreSQL 保存不可变发布与候选快照，替代运行时 Git 仓库，避免 refs 与权限、审计的双重提交。
每页单独提案限制跨页面 ACL 和原子发布的组合复杂度，代价是应用负责 diff、三方合并和撤销。
新建直接发布，已有页面通过明确 head/候选的合并发布，不设独立批准轮次；合并者承担检查责任。
媒体是独立 Page，文档固定引用媒体发布快照，避免媒体替换悄然改变已发布正文。
Page 与 Account 使用数字稳定标识，标题不承担身份或路由职责；旧 UUID 数据库不做隐式转换。

## 模块边界

采用模块化单体与消费方小接口，避免提前引入服务发现、跨进程事务或消息队列。
Core 统一业务与授权，REST/MCP 只做协议映射，Web 不复制状态机。
代价是必须持续用依赖边界检查阻止模块之间访问私有实现。

## 认证与授权一致性

人和 Agent 共用账户，账户最多一个有效 Token，轮换与撤销简单明确，代价是多个客户端共享撤销边界。
服务端会话配套 CSRF；同源恢复写入凭证不延长会话、不自动重放写入，避免页面刷新导致会话状态漂移。
统一授权事务锁串行化撤权与发布，优先保证提交顺序；代价是吞吐受限，缩小锁粒度必须有测量与竞态证据。
网络读取不持锁，最终响应事务重新复核当前权限和快照，不能以性能为由复用旧授权。
隐藏内容通过显式治理入口访问，普通读取即使由管理员发起也不隐式返回隐藏正文。

## 媒体与恢复

本地不可变文件配合上传租约、ready 状态与 GC 墓碑，避免文件操作和数据库失败产生半发布。
不做跨账户去重，所有候选和发布历史保护原件；代价是存储增长，清理不能绕过引用和权限检查。
采用维护窗口停止写入后备份数据库与原件，恢复默认撤销旧凭证并重建索引。
代价是停机窗口及备份点后的数据损失风险；不承诺在线备份一致性或跨 schema 原地降级。
SQL 迁移内嵌、校验和固定，显式命令整批事务执行，启动只验证而不自动迁移。

## 检索与证据

Meilisearch 提供中英文全文候选，PostgreSQL 决定可读性与当前发布内容，outbox 负责可恢复投影。
要求所有查询词匹配，避免放宽查询得到无关结果；代价是可能降低召回。索引落后不能降低权限标准。
目录采用数值 ID 锚点，搜索按需批量复核，有界扫描避免一次读取全部候选；空页可继续携带游标。
固定发布快照的段落、源行和章节提供可追溯引用，不能把标题命中等同于正文证据。
MCP RAG 使用确定性问题规划、子句绑定、保守指代消解和有界多路全文召回；不依赖模型或向量服务。
RRF 融合减少单路排名偏差，主体公平分配和段落预算控制成本；截断、歧义及未知条件必须显式报告。
主体存在性与属性覆盖分离，只用实际返回证据逐项判定完整性，代价是复杂问句可能保守返回未验证。
具体语法、预算和状态统一见[业务规则](../business-rules.md#检索与证据)，禁止按题目或答案硬编码。

## Web 与工具链

以搜索和 Page 为中心的导航匹配无层级知识模型；统一页面工具替代全站提案页和侧边栏。
身份变化清空响应与内存草稿，不持久化受限内容；代价是离开页面需提示未保存内容。
前端内嵌于服务镜像简化同源认证与部署，生产产物需同时验证 API 与 SPA 路由边界。
契约生成器与 Web 编译器使用独立依赖树，满足生成器 peer dependency，避免强制安装绕过不兼容。
生成声明仍由应用编译器检查，每个构建先安装根目录再安装 Web 依赖；精确版本由锁文件维护。
